# ADHD Community Soft Launch Kit

Use this kit to share **i-have-adhd** with people who have ADHD, people exploring possible symptoms, and people who support them.

## 1) Audience segments

1. People with diagnosed ADHD who want lower-friction help while using AI tools.
2. People with ADHD-like symptoms (focus loss, overwhelm, task paralysis) who want structured responses.
3. Parents, educators, and ADHD coaches who support others using technology.

## 2) Message versions (copy/paste)

### Version A — ADHD support tool

I built **i-have-adhd**, a free MIT-licensed skill/plugin that makes AI replies ADHD-friendly: next action first, numbered steps, low fluff.

It usually saves me 1–3 minutes per question because I stop scrolling and can start immediately.

It does **not** diagnose ADHD and does **not** require personal medical data.

If you want to try it: https://github.com/ayghri/i-have-adhd  
If you test it, reply with one thing that felt clearer or still confusing.

### Version B — If you struggle with focus

If AI answers feel long or hard to act on, try **i-have-adhd**.

It restructures responses so you get the next action first, short numbered steps, and one clear next move.

No diagnosis needed. No medical claim. You can use it even if you just struggle with focus/overwhelm.

Try it here: https://github.com/ayghri/i-have-adhd  
If you test it for 1 day, share what changed in your workflow.

### Version C — Productivity support for neurodivergent users

Sharing **i-have-adhd** for neurodivergent-friendly AI output.

Goal: reduce cognitive load by making answers concrete, sequential, and immediately actionable.

Privacy: it is a local skill/plugin setup flow from a public repo under MIT license.  
Medical note: this is a communication-format tool, not diagnosis or treatment.

Repo: https://github.com/ayghri/i-have-adhd  
Looking for feedback from ADHD users, coaches, and educators.

## 3) Channel set

1. Reddit ADHD communities (read each subreddit's self-promo rules first).
2. ADHD/neurodivergent Discord or Slack groups (ask moderators before posting links).
3. LinkedIn or X with focused tags (`#ADHD`, `#Neurodiversity`, `#Productivity`, `#AIAgents`).
4. Direct outreach to ADHD creators/newsletters (short intro + one-sentence benefit + repo link).

## 4) 7-day soft-launch cadence

1. Day 1: post 3 variants in 3 channels.
2. Day 3: collect and tag feedback (clarity, trust, install friction, impact).
3. Day 5: tighten message wording and onboarding hints based on feedback.
4. Day 7: repost improved version in the same channels with a concise "updated based on feedback" note.

## 5) Success criteria

Use `launch/reply-tracker.csv` to track:

- impressions
- clicks
- installs
- activation
- 24h retention
- feedback themes

Week-1 win target: **10+ meaningful user responses**.
